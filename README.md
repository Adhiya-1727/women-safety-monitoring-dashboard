# Women Safety Monitoring Dashboard
A web-based safety monitoring dashboard designed to visualize real-time safety conditions using pulse, motion, and voice indicators.

## Project Overview
This project provides a simple and interactive interface for monitoring women's safety conditions. It displays sensor-related information, calculates a risk score, records alerts, and provides a clear emergency status.

## Key Features
- ❤️ Pulse / heart-rate monitoring
- 📈 Real-time pulse waveform visualization
- 🏃 Motion status monitoring
- 🎙️ Voice / distress detection status
- 🛡️ Dynamic risk score
- 🟢 Safe, 🟡 Warning and 🔴 Emergency modes
- 🔔 Alert history
- 📊 Safety statistics
- ⚙️ System status and settings
- 📱 Responsive dashboard interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Java
- GitHub

## Dashboard Modules
1. **Dashboard** – Overall safety status and risk level
2. **Live Monitoring** – Pulse, motion and voice monitoring
3. **Alert History** – Records warning and emergency events
4. **Statistics** – Displays safety event statistics
5. **Settings** – Shows connected monitoring components

## Purpose
The main objective is to provide a user-friendly monitoring interface that can support intelligent threat detection and rapid emergency response.

## Future Scope
The dashboard can be integrated with real-time wearable sensors, Edge AI models, GPS location tracking and automated emergency notification systems.
